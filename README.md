# Fantasy Local ⚽

Aplicación web estilo Fantasy centrada en un único equipo (ideal para peñas, clubes de barrio o ligas de amigos).

## Características principales
* **Banner de Próximo Partido**: Muestra el rival, fecha y hora límite para alinear.
* **Sistema de Autenticación**: Registro e inicio de sesión seguro.
* **Economía**: 20 rupias iniciales por participante.
* **Mercado y Plantilla**: Compra y venta de jugadores (máximo 5 en plantilla, 4 titulares).
* **Tabla de Clasificación**: Ranking general por puntos acumulados.
* **Panel de Administrador**: Gestión de futbolistas, partidos y carga de puntos tras cada jornada.

## Instalación local
1. Instalar dependencias: `pip install -r requirements.txt`
2. Ejecutar la app: `streamlit run app.py`
